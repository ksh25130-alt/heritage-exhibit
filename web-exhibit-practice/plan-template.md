## 제작 조건

첫 실습은 GitHub Pages에서 공개할 수 있는 HTML·CSS·JavaScript 정적 사이트로 만듭니다. `index.html`을 최상위에 두고 내부 자료는 상대경로로 연결합니다. 별도 빌드나 서버·API 키가 필요한 기능은 제외합니다. 실제 자료와 없는 자료를 구분하고, 누락된 사진이나 역사 정보를 임의로 생성하지 않습니다.
