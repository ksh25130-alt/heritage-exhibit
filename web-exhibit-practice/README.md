# 웹전시 바이브코딩 실습 꾸러미

디지털헤리티지 큐레이터 4기 · 김재승 · 2026. 11. 12–13

이 자료로 **내 전시 기획을 MD로 정리하고, AI와 웹전시를 만든 뒤, GitHub Pages 공개 주소로 관람**합니다. 예제의 주제는 연습용입니다. 본인이 고른 주제로 바꿔도 됩니다.

## 파일을 사용하는 순서

| 파일 | 언제 사용하는가 |
| --- | --- |
| `plan-example.md` | 기획 의도, 화면, 자료, 관람 행동이 연결된 완성 예제를 읽을 때 |
| `plan-template.md` | 자기 전시의 기획을 작성할 때 |
| `sources.md` | 자료의 명칭, 출처, 파일명, 공개 이용 조건을 기록할 때 |
| `prompts.md` | AI에게 계획, 제작, 수정, 공개 준비를 요청할 때 |
| `student-guide.md` | Codex 또는 Antigravity로 제작하고 GitHub Pages로 공개할 때 |
| `submission.md` | 공개 주소, 테스트 결과, 남은 작업을 제출할 때 |
| `instructor-runbook.md` | 강사가 시간 배분과 시연 순서를 확인할 때 |

## 바로 시작하기

1. ZIP 압축을 풀고 작업용 폴더를 만듭니다. 예: `heritage-exhibit`.
2. 예제로 연습하면 `plan-example.md`를, 자기 주제로 만들면 `plan-template.md`를 복사해 **`plan.md`**로 저장합니다.
3. 같은 폴더에 `sources.md`를 복사합니다. 자료용 `assets` 폴더를 만듭니다.
4. Codex 또는 Antigravity에서 이 작업 폴더를 엽니다. 둘 중 하나만 사용합니다.
5. `prompts.md`의 1번 요청문으로 시작합니다.

MD는 제목과 목록을 쓸 수 있는 일반 텍스트 문서입니다. 메모장으로 열어도 됩니다. Windows에서는 파일 확장명을 표시하고 `plan.md.txt`가 되지 않았는지 확인합니다. `#`은 큰 제목, `##`은 작은 제목, `-`는 목록입니다.

**이 꾸러미에는 유물 사진과 완성 웹사이트 코드는 들어 있지 않습니다.** 사진을 준비하기 전에도 빈 이미지 자리로 화면과 기능을 실습할 수 있도록 MD에 조건을 넣었습니다. 실제 전시 이미지는 직접 확보하고 이용 조건을 확인해 연결합니다. 이미지가 없는 상태로 공개한 경우 제출물에 ‘구조 실습본’이라고 표시합니다.

첫 실습은 별도 빌드가 필요 없는 HTML·CSS·JavaScript 방식입니다. 코드 문법을 외우기보다 **내 의도대로 자료가 보이는지, 관람 행동이 작동하는지**를 확인합니다.
